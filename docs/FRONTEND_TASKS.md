## 1. Визуальная проверка новых экранов — приоритет высокий

Проверить на ширине 375 px, 768 px и 1440 px и подогнать под дизайн-макет:

- регистрация: индикатор надёжности, список требований, ошибки «Пароли не совпадают», кнопка «Показать»;
- календарь: точки статусов в ячейках (заливка = выполнено, кольцо = запланировано, бледная = пропущено), легенда, список дня, блок «Привычки с интервалом»;
- профиль: плашка подтверждения email;
- модалка привычки с включённым интервалом.

Готово, когда: ничего не вылезает за экран на 375 px, все элементы в стиле существующего дизайна, логика не изменена.

## 2. Выбор дней недели в форме привычки — приоритет средний

Бэкенд поддерживает `schedule: { type: 'weekdays', days: number[] }` (ISO: Пн = 1 … Вс = 7), а форма умеет только «ежедневно» и «интервал». Существующее расписание по дням недели при редактировании сохраняется, но создать его нельзя.

- В `ItemModal` сделать переключатель «Ежедневно / По дням недели / Интервал»; для дней недели — 7 кнопок-чипов, минимум один день.
- Календарь и подписи уже работают с этим типом (`scheduleLabel`, `nextScheduledDate`), там ничего менять не надо.

Готово, когда: можно создать и отредактировать привычку «Пн, Ср, Пт», в календаре она стоит только в эти дни.

## 3. Экран напоминаний — ✅ сделано (страница «Напоминания», уведомления, см. `docs/notifications-setup.md`)

Сервисы бэкенда уже есть: `getReminders`, `createReminder`, `updateReminder`, `deleteReminder`, `snoozeReminder`, `completeReminder`; утилиты `reminderOccursOn`, `nextReminderOccurrence`. Типы: `Reminder`, `ReminderInput`, `ReminderSchedule` (`repeat`: once / daily / weekdays / weekends / weekly / custom).

- Сделать страницу или раздел «Напоминания»: список, создание/редактирование (название, время `HH:MM`, повторение, даты начала и конца), включение/выключение, удаление.
